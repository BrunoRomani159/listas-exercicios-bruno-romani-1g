Respostas dos checkpoints — Etapas 5 a 8

Etapa 5

1. A média é 6,875.

2. O primeiro índice de um array é 0 e o último é length - 1.

3. for (let i = 2; i <= 10; i += 2) { console.log(i); }

4. O resultado da soma é 10.

Etapa 6

1. A função imprime undefined porque não possui return. Correção: function soma(a, b) { return a + b; }.

2. function ehPar(n) { return n % 2 === 0; }

3. console.log(x) mostra o valor no console. return x devolve o valor para quem chamou a função.

Etapa 7

1. O JavaScript pode tentar acessar os elementos antes de o HTML carregar e receber null. Usar defer evita esse problema.

2. A cada clique, a variável cliques aumenta em 1 e o contador da página é atualizado.

3. Usamos let porque o valor do contador muda a cada clique.

Etapa 8

1. A média é calculada somando as duas notas e dividindo o resultado por 2.

2. A função retorna (nota1 + nota2) / 2. Os parênteses garantem que a soma aconteça antes da divisão.

3. A validação verifica se os campos foram preenchidos e se as notas estão entre 0 e 10.

4. Para as notas 8 e 7: média 7,5 — Aprovado.

5. Para as notas 5 e 6: média 5,5 — Abaixo da média.

6. Para as notas 6 e 6: média 6,0 — Aprovado.

7. Para as notas 10 e 10: média 10,0 — Aprovado.

8. Campo vazio ou nota fora do intervalo: o programa mostra uma mensagem de erro.

Checkpoint 1. Separar o cálculo em uma função deixa o código mais organizado e permite reutilizar essa parte.

Checkpoint 2. Para mudar a média mínima, basta alterar o valor da constante MEDIA_APROVACAO.
